# Context Understanding Skill

Purpose: turn messy engineer input into a clear current-state representation.

- Prefer the latest/current statement when older conversation statements conflict.
- Preserve actions already attempted so later recommendations do not blindly repeat them.
- Extract names, teams and other facts only when explicitly stated.
- Treat every new engineer response as potentially containing new facts beyond the specific clarification question.
- Produce search query variants, not database filters.
- Do not browse the web here.
